# Decathlon India clone (academic)
`npm install && npm run dev` · `npm run validate` checks the data files.
- Reviews: 120 per product in `src/data/review/` (P001.js ... P007.js), combined by `src/data/reviews.js`.
- Site-wide rating stats: `src/data/reviewStats.js`. Prices: fill the `null` ones in `src/data/products.js`.
- Structure: every page/component has its own folder with one .jsx and one .css.
